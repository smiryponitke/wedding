# Wedding Invitation Site — Егор + Вика

## Context

Свадебный сайт-пригласительное для Егора и Вики (свадьба 29.08.2026). Гости получат ссылку, увидят информацию о свадьбе и заполнят анкету. Ответы из анкеты приходят женихy в Telegram.

## Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Deploy:** Vercel (free tier)
- **Notifications:** Telegram Bot API via Vercel Serverless Function

## Visual Style

Современный минимализм: белый фон, тёмная типографика, много воздуха, serif-шрифты для заголовков.

## Config File

Все изменяемые данные вынесены в `src/config.ts`:
- Имена, дата свадьбы
- Локация (название, адрес, ссылка на карты, время сбора)
- Тайминг (список событий: время + название)
- Дресс-код (цвета + текст)
- Дедлайн анкеты
- Контакты

## API: /api/rsvp

Vercel Serverless Function (POST):
- Принимает данные формы
- Форматирует сообщение
- Отправляет в Telegram через Bot API
- Переменные окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`

Telegram credentials:
- Bot Token: хранится в `.env.local` и Vercel Environment Variables
- Chat ID: 455902766

## Responsiveness

Mobile-first. Breakpoints: mobile (< 640px), tablet (640–1024px), desktop (> 1024px).
Поляроидные фото на мобайле — вертикально стопкой, на десктопе — рядом.

## Deployment

1. `git push` на GitHub
2. Vercel подключается к репо, деплоит автоматически
3. Домен: `egor-vika.vercel.app` (или свой)
4. Env vars добавляются в Vercel Dashboard
